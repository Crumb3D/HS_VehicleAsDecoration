# HS Vehicle As Decoration changelog

**1.0.8** — Runs on 7 Days to Die 3.4, and still on 3.0–3.3 with the same download. It used to refuse to load on 3.4.

**1.0.7** — The world editor preview shows the vehicles. A prefab file does not store the live shell, and that preview is drawn from blocks, so each anchor now carries the vehicle mesh. The minibike is held on its anchor so it does not drop out of the prefab editor.

**1.0.6** — Placing a shell in the prefab editor shows it immediately. That mode does not run block ticks, so the shell used to vanish after you placed it.

**1.0.5** — Decoration shells are listed in the prefab editor creative menu as well as the normal one. Search for "decoration".

**1.0.4** — The same DLL loads on 7 Days to Die 3.2 and 3.3. 3.3 had changed `holdingEntity` from a field to a property, which stopped the 3.3 build from loading on 3.2.

**1.0.3** — A shell placed in a prefab stays there. The prefab keeps a hidden block under the vehicle and spawns the shell again when the prefab loads, mods included. Take is off.

**1.0.2** — Craftable bicycle, minibike, motorcycle, 4x4, and gyrocopter shells. Full wheel counts and mod slots, no engine or battery. They cannot be driven, refueled, or bought by a trader. Icons match the real vehicles. Bikes stay upright.
